## Hook acceptance

Verify:

```text
globalThis.WorldLedger
WorldLedger.onInput
WorldLedger.onContext
WorldLedger.onOutput
WorldLedger.processOutput
```

Input hook initializes state, routes commands, suppresses command output, and never treats input as completed success.

Context hook builds read-only context and never mutates gameplay state.

Output hook skips command output, skips duplicate output consequences, scans only valid story output, validates before reducer, routes only accepted results, marks dirty targets, runs support-layer caps, and returns original output text.

## Pass / warn / fail

PASS if hooks, commands, ReleaseCheck, foundationcheck, hookcheck, playerbreakercheck, regressioncheck, supportcheck, and packagingcheck pass with no unsafe active behavior.

WARN only for honest deferred systems or shell limitations.

FAIL if script does not load, exports are missing, commands crash, command/context/card text mutates state, duplicate output repeats effects, manual mutation is enabled, generated cards are enabled, live card writes are enabled by default, or ReleaseCheck fakes PASS.
