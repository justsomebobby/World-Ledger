# 5. Source freeze rules

Before coding, freeze the source package.

Create a source manifest:

```text
source file name
role
trusted/reuse/quarantine/deferred
hash
notes
```

Old scripts may be reused only if:

```text
the code is understandable
the code fits the owner reducer model
the code does not parse command/context/card output as canon
the code is duplicate-safe or can be wrapped with operation keys
the code has no manual mutation shortcuts active
the code can be tested in AI Dungeon hooks
```

Old scripts must be quarantined if:

```text
they mutate state directly from raw output
they treat cards/context as canon
they do broad cleanup across owners
they grant items/abilities/stats/XP without validation
they duplicate rewards or effects on replay
they silently rewrite schema
```

# 6. AI Dungeon hook order lock

Codepass 1 must define the hook pipeline clearly.

Recommended order:

```text
1. Input hook receives user input.
2. CommandRouter checks if input is command.
3. Commands render display-only output and mark source-blocked.
4. Non-command input enters EventScannerLite as intent/hint only.
5. Output hook receives AI Dungeon model output.
6. SourceClassifier blocks command/context/card/debug/releasecheck output from mutation.
7. EventScannerLite scans safe input/output for hints.
8. ProposalBuilder creates local clause proposals.
9. CanonValidator accepts/rejects/pends proposals.
10. Resolver binds targets with owner-specific sanitizers.
11. ReducerRegistry routes accepted proposals to owner reducers.
12. Owner reducers mutate only owned paths.
13. OperationLedger records durable/recent keys.
14. DirtyQueue marks affected displays/context/card mirrors.
15. InvariantChecker validates state.
16. ContextBuilder rebuilds filtered context.
17. CardSyncLite produces dry-run mirrors only.
18. ReleaseCheck/Regression commands inspect but do not mutate gameplay truth.
```

No hook may allow context/command/card output to become fresh canon.

# 17. Failure-stop conditions

Stop the release immediately if any occur:

```text
AI Dungeon script syntax/runtime crash
state root corruption
context/command/card output mutates gameplay state
manual mutation command works
duplicate reward/XP/damage/healing possible
owner reducer writes another owner path directly
hidden lore leaks
quest promise pays reward
visible item becomes owned
ability output-only claim becomes stable
current form overwrites true race
player level scales world threats
Story Card creates active encounter or item/property/form/quest
CardSync writes live cards by default
cleanup deletes active truth or durable keys
ReleaseCheck has FAIL/BLOCKED
```

Do not patch around these casually.
Fix the owner/gate/source problem.
