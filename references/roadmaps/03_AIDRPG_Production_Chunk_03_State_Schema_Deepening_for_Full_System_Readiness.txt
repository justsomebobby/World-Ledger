# AIDRPG Production Chunk 03 — State Schema Deepening for Full System Readiness

## Document status

Production sequence: 03 of 25.
Build target: WorldLedger V0.17.2 command-surface accepted build.
Purpose: Deepen state schema, migration metadata, invariant scaffolding, disabled placeholders, operation ledgers, and quarantine categories before live gameplay expansion.

## Doctrine

```text
Prepare state before features.
Add structure before automation.
Add placeholders without enabling unsafe systems.
Add migration metadata before migration complexity.
Add invariant shells before high-risk reducers.
Keep old prose quarantined, not imported.
```

## Allowed changes

```text
State schema factories
StateManager default creation and missing-field repair
schema version metadata
bucket version metadata
migration metadata
quarantine categories
operation ledger bucket structure
feature flag placeholders

ReleaseCheck schema gates

```

Forbidden:

```text
active economy/crafting/combat/reputation/domain/absorption/generated cards/manual mutation
old card prose gameplay import
```

## Canonical root rule

There must be one canonical root:

```text
state.worldledger
```

Do not create competing active roots such as `state.aidrpg`, `state.tasis`, `state.tas`, `state.innerSelf`, or `state.autoCards`. Old roots may be detected and quarantined as legacy evidence.

## Required top-level buckets

```text
meta features runtime startup player body progression inventory abilities quests actors places time cards operationLedger audits migration quarantine dirty cleanup schema integrity
```

StateManager adds missing safe defaults without deleting valid existing data.

## Deferred feature placeholders

Feature flags must distinguish active foundation systems, disabled future systems, shell diagnostics, and blocked unsafe systems. Required disabled flags:

```text
economyEnabled craftingEnabled investigationEnabled reputationEnabled domainEnabled absorptionEnabled advancedCombatEnabled warfareEnabled multiProtagonistEnabled partyAdvancedEnabled generatedCardsEnabled protectedCardWritesEnabled manualMutationCommandsEnabled = false
```

Add display metadata with planned chunk/reason, for example economy planned for 23A, crafting 23B, investigation 23C, reputation 23D, domain 23E, advanced combat 24A, party 24B, absorption 24C, multi-protagonist 24D, warfare 24E.

## Bucket readiness requirements

### Startup

```text
locked, firstGameplayInputSeen, setupSourceStatus, setupSourceKey, identityLockedAtTurn, startupOperationKeys, importedFields, unknownFields, warnings, notes
```

Post-lock setup cannot overwrite protected identity.

### Player

```text
id, displayName, aliases, identityStatus, origin, worldKnowledgeStatus, trueRaceSpecies, lineage, currentForm, bodyType, disguise, illusion, presentation, protectedFields, candidateTraits, pendingTraits, warnings, notes
```

Unknown race does not mean human. Current form does not overwrite true race/species.

### Body

```text
resources.hp/mp/ep, fatigue, conditions, injuries, deathBoundary, bodyTraits, formConstraints, warnings, notes
```

Structural clamp is not healing.

### Progression

```text
level, currentXP, totalXP, xpToNext, stats, baseStats, modifiers, derivedSnapshot, statXP, histories, formulaProfile, formulasEnabled, warnings, notes
```

Formulas remain disabled/limited until formula chunks.

### Inventory

```text
items, equipped, stored, sceneItems, custody, currency, itemHistory, warnings, notes
```

Future ItemRecord shape includes id, key, displayName, quantity, category, tags, stackable, durability, accessState, owner/custody/source metadata.

### Abilities

```text
records, stable, unstable, candidates, hints, failed, sealed, unavailable, evidenceLog, warnings, notes
```

Candidate is not stable.

### Quests

```text
records, active, offered, rumored, readyToTurnIn, completed, failed, abandoned, rewardLedger, warnings, notes
```

Promised reward is separate from paid reward.

### Actors

```text
records, sceneActors, present, absent, referenceOnly, memories, relationshipNotes, warnings, notes
```

Reference-only actor is not present.

### Places

```text
currentLocation, currentScene, records, travelIntent, visibleReferences, nearbyReferences, routeReferences, sceneHistory, warnings, notes
```

Travel intent is separate from current location.

### Time

```text
text, turn, sequence, lastAdvance, acceptedAdvances, pendingClaims, deadlines, agePolicy, warnings, notes
```

Time advance and age mutation are separate.

### Cards

```text
protectedCards, registry, dirtyCards, tombstones, duplicateWarnings, apiStatus, syncMode, lastDryRun, warnings, notes
```

Generated cards and protected live writes remain disabled.

Migrations must be deterministic and idempotent. Write new version only after success. Failed migration preserves old payload in quarantine/backup.

## IntegrityChecker shell

Should check required buckets, safe feature flags, numeric resources, current <= max, nonnegative item quantities, duplicate stable ability keys, duplicate active quests, deathBoundary values, generated cards disabled, manual mutation disabled, durable ledger buckets, and inactive quarantine.

It may report PASS/WARN/FAIL/QUARANTINE. It may not award, heal, pay, or repair gameplay effects.
