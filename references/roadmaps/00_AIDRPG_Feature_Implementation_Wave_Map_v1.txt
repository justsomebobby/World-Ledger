# AIDRPG Feature Implementation Wave Map v1

## Purpose

This document is the bridge from WorldLedger V0.17 Foundation Candidate to the full AIDRPG build. It prevents the project from restarting the original Design Bible Chunks 1–32/33 as blind manual testing sessions.

The original Design Bible Chunks remain the full design source. This roadmap converts them into controlled production waves with owners, gates, tests, and forbidden shortcuts.

## Current authority stack

1. Final Build Control Map v1 — old failures become owner/rule/test/release gates.
2. WorldLedger V0.17 — current foundation candidate and hook/export baseline.
3. Build Chunks 1–17 — implementation safety overlay and Code Pass 1 rules.
4. Gap Chunks A–G — old failure protections.
5. Regression Matrix / QA files — pass/fail authority.
6. Formula Appendix — progression/stat math authority.
7. Developer Spec / MVP Spec — intended implementation behavior.
8. Design Bible Chunks 1–32/33 — full game destination.
9. World Bible / Story Cards JSON — lore/reference source, not direct gameplay truth.
10. Old scripts and tester feedback — evidence only, not blind code source.

## Remaining production count

From V0.17 onward:

```text
24 production chunks
+ 1 final packaging/release chunk
= 25 total remaining production chunks
```

This is not 32 manual play/build sessions. It is a finite feature-wave implementation plan.

## Process required for every production chunk

Every production chunk must state:

```text
1. Exact goal.
2. Modules touched.
3. State fields added/changed.
4. Parser/proposal/validator changes.
5. Reducer changes.
6. Command/context/card changes.
7. Operation keys.
8. ReleaseCheck gates.
9. Regression tests.
10. Forbidden shortcuts.
11. Implementation order.
12. Pass/warn/fail criteria.
13. Handoff to the next chunk.
```

No production chunk may end with “just play and see what breaks.” Manual playtesting verifies feel; regression tests protect old failures.

## Final doctrine

```text
No blind 32-session rebuild.
No manual rediscovery loop.
No feature activation without owner/rule/test/gate.
No old patch pasted blindly.
No PASS on uncertainty.
Build the full game through controlled production waves.
```
