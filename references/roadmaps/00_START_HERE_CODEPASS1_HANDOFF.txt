Absolute build doctrine
Input may intend.
Context may remind.
Output may propose.
ParserHits are observations.
EventProposals are structured claims.
CanonValidator decides eligibility.
ReducerRegistry routes.
OwnerReducers commit.
OperationLedger dedupes.
DirtyQueue marks mirror/context refresh.
Context reads.
Cards mirror.
ReleaseCheck tells the truth.

Forbidden Code Pass 1 shortcuts
- No parser direct writes.
- No card-to-canon path.
- No context writes.
- No command output parsing as story.
- No generated cards in MVP.
- No live CardSync writes by default.
- No manual mutation commands.
- No old card prose imported as canon.
- No cleanup deleting active truth.
- No broad shared sanitizer that strips ability phrases globally.
- No output-only ability hard-save.
- No promised reward payment without payment validation.
- No visible item becoming owned inventory.
- No weak place mention becoming current scene.
- No quoted/dreamed/rumored/revoked/denied text becoming canon.

Code Pass 1 target
Build the smallest stable truth engine that initializes, inspects, audits, validates, reduces limited safe events, blocks unsafe sources, keeps support layers non-canon, and passes ReleaseCheck/regression gates.
